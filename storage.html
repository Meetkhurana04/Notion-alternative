How your notes are stored

The short version. Three places, one direction.

you type
 ↓  (auto, ~instant)
📄 file on your computer — data/nn_xxx_title.json
 ↓  (only when you press 🚀)
☁️ your private GitHub repo — backup + other devices

1. You type → saved to a file

Every note is one JSON file in the data/ folder. You stop typing, it saves. No button needed.

That folder is the truth. Open the app → it reads that folder fresh. Nothing hidden in the browser.

2. You press 🚀 → sent to GitHub

The rocket button does git add → commit → push to your repo. That's your backup.

No 🚀, no backup. Your notes are still safe on disk — just not on GitHub yet.

Delete doesn't really delete

Deleting a note writes "deleted": true into its file. The file stays. The app just hides it.

Push never removes files from GitHub either. Only you can do that (on GitHub, or git rm).

Two windows, same note?

The older window's save is refused and you get a warning. So an old copy can't overwrite newer work.

Where is the folder?

Desktop app: Account → Show notes folder in the menu. Usually Documents/NovaNotes/<repo>.

New computer? Log in, pick the same repo — it downloads everything.

Heads up: the app doesn't pull. If you edit on two computers, push on one, then run git pull in the notes folder on the other before editing there.

Login stuff

GitHub login gives the app a key. It's locked in your OS keychain, never written into the repo. Sign out with Account → Switch account / repo — your notes stay put.
